# Ball Knower App Store Screenshot Plan

Capture these from the exact TestFlight build after the device gate. Do not mock unsupported functionality.

1. Home — compact Ball Knower dashboard with current football/fantasy content.
2. Fantasy matchup — both teams visible head-to-head with projections/live scoring treatment.
3. Team / lineup — starters, FLEX, bench, projections, and player imagery.
4. Player intelligence — player details, game log, schedule, projection/research context.
5. Add Players / Waivers — compact free-agent research and transaction controls.
6. Draft experience — draft room / draft-order game / advisor treatment, whichever is strongest and production-ready.
7. Trivia or another original Ball Knower game mode — demonstrate the app is broader than a generic fantasy client.
8. League/social or power-ranking view — only if the tested build is visually clean and fully functional.

Keep text readable at App Store thumbnail size. Avoid showing personal email addresses, private league invite codes, or test/debug UI.
