# Player Headshot Rights

Ball Knower must use only player photos with documented reuse rights.

## Policy

- Prefer Wikimedia Commons images with licenses that permit commercial reuse.
- Store source URL, author/creator, license name, license URL, and any required attribution for every mapped image.
- Do not use EA/Madden, ESPN, Getty, NFL/team, or other third-party imagery unless Ball Knower has explicit rights to use it in a commercial app.
- If no approved image exists for a player, use the Ball Knower-generated initials/silhouette fallback.
- Never silently fall back to an unlicensed third-party image.

## Release gate

Before release, verify every mapped image still has a documented commercial-reuse license and that required attribution is displayed or otherwise provided as required by that license.
