# Community section graphics

Extends the approved black/gold photographic design to the four requested Community views: Rankings trophy banner/podium, Trivia H2H film-room scene/results vault, Football H2H helmets/practice stadium/records locker, and Mini Games stadium plus crews/trophy-room image buttons.

Existing artwork is reused except for one original AI-generated text-free film-room photograph, exported as 1280px and 768px WebPs (96,592 bytes combined). Copy, live names/scores, matching, account gates, disclosure and result behavior remain real components. Trivia Quick Match now uses an explicit high-contrast gold fill and dark label; technical server-scoring text is replaced with plain scoring guidance.

Manual cloud-browser review used real components with explicit isolated fixtures at 320px. Rankings, Trivia, Football and Mini Games imagery rendered without horizontal overflow. No fixture routes are included in production. Expanded existing CI browser coverage checks actual loaded photographs in all four sections, card counts and overflow at 320/390/430/1280px while retaining authentication/action regressions. Build/check results and final production verification are recorded in the PR.
