# Solo player universe: approved visual direction

Elijah approved the realistic Blake Hartwell black/gold cinematic player-profile concept and requested that quality throughout all six Solo experiences: Cap Challenge, Solo Fantasy Draft, Franchise Command, My Player, Agent Mode and Owner Office.

The target is a complete fictional football presentation: consistent faces, believable body types, original team uniforms, polished dense cards and usable mobile profiles. It is not fulfilled by decorative mockups or passing builds alone.

The first shared system is now integrated on the development branch in PR #280. See ../qa/SOLO_PRESENTATION_STATUS.md for exact delivered behavior, tested commit, measurements and release blockers.

Preserve all existing careers, gameplay, drafts, trades, permissions, authentication and iOS configuration. Keep real fantasy-player imagery separate. Use reusable compressed assets with on-demand detailed rendering and compact appearance records. Ordinary player viewing must not call an AI image-generation API.

The current nine-face/one-body art pack is a prototype and has NOT passed reference-fidelity review. Do not describe the six-mode redesign as complete or merge it as release-ready until the documented visual and device gates are closed.
